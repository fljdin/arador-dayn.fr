WoW5thAniversary Template created by Reinhart for Guild EquisDe Eu - Zul'jin Alliance www.clan-equisde.com.es
Based on the World of Warcraft 5th Aniversary Web

Includes 4 languajes, English, German, French and Spanish also includes de PSD files to easily create new ones.

This template uses 'border-radius' CSS3 property wich is not supported by IE8, but its works fine in Mozilla, Firefox and Chrome.
It also uses 'box-shadow'wich it should work on most browsers.

Most of the images used on the template are property of Blizzard Entertaiment http://www.blizzard.com 
Some of the icons were designed by Vhael http://vhael.deviantart.com/gallery/#/d1lhokb
This template is only for fan, and clan pages, use it properly and do not use it for any commercial purposes.
Please do not delete the footer credits, if you use it and change things to the style, leave at least a reference link to the original work.
